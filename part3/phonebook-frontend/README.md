# Phonebook Frontend

A RESTful phonebook application built during the Full Stack Open course (University of Helsinki).

## Tech Stack

- **Frontend**: React, Vite, Axios
- **Backend**: Express, MongoDB, Mongoose
- **Linting**: ESLint

## Getting Started

```bash
# Install dependencies
npm install

# Run frontend
npm run dev

# Run backend (from phonebook-backend/)
cd ../phonebook-backend
npm install
npm run dev
```

## Features

- CRUD operations for phonebook contacts
- Search and filter contacts
- Error notifications with alerts
- Axios-based API communication with request/response logging
