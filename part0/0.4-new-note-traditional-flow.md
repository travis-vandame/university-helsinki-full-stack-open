> **Task:** 0.4 New Note Traditional Flow

This diagram describes the network traffic and browser operations that occur when a user submits a new note in the traditional web application flow.

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant Browser
    participant Server

    activate User
    User->>Browser: Enter Note Click "Save"
    deactivate User

    activate Browser
    Browser->>Server: REQUEST <br/> POST https://studies.cs.helsinki.fi/exampleapp/new_note
    deactivate Browser

    activate Server
    Note over Server: Append JSON Data File
    Server-->>Browser: RESPONSE <br/> Content-Type: application/x-www-form-urlencoded <br/> Location: /exampleapp/notes <br/> Status Code: 302 Found <br/>
    deactivate Server

    activate Browser
    Note over Browser: Trigger Redirect To Response Location
    Browser->>Server: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/notes
    deactivate Browser
    
    activate Server
    Server-->>Browser: RESPONSE <br/> Content-Type: text/html charset=utf-8 <br/> Notes HTML Document Data <br/> Status Code: 200 OK
    deactivate Server

    Browser->>Server: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/main.css
    activate Server
    Server-->>Browser: RESPONSE <br/> Content-Type: text/css charset=UTF-8 <br/> CSS Code Data <br/> Status Code: 200 OK
    deactivate Server

    Browser->>Server: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/main.js
    activate Server
    Server-->>Browser: RESPONSE <br/> Content-Type: application/javascript charset=UTF-8 <br/> JavaScript Code Data <br/> Status Code: 200 OK
    deactivate Server

    activate Browser
    Note over Browser: Browser executes main.js resulting <br/> in a request for data.json from the server
    Browser->>Server: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/data.json
    deactivate Browser

    activate Server
    Server-->>Browser: RESPONSE <br/> Content-Type: application/json charset=utf-8 <br/> JSON Data: [{"content": "Hello From Austin Texas", "date": "2026-07-22"}] <br/> Status Code: 200 OK
    deactivate Server

    activate Browser
    Note over Browser: Browser executes callback function <br/> in main.js that renders notes
    Browser->>User: Display updated notes page
    deactivate Browser
```
