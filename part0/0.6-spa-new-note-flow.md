> **Task:** 0.6 New Note in Single Page App (SPA) flow

This diagram describes the network traffic and browser operations that occur when a user submits a new note in the Single Page App.

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant DOM as Browser
    participant JS as spa.js
    participant API as Server

    activate User
    User->>DOM: Enter Note Click "Save"
    deactivate User

    activate DOM
    DOM->>JS: Trigger "Submit" Event Listener
    deactivate DOM

    activate JS
    Note over JS: Prevent Default Submit
    Note over JS: Block Page Reload
    Note over JS: Append Note List
    JS->>DOM: Redraw Note List
    deactivate JS

    activate DOM
    Note over DOM: No Page Reload
    DOM->>User: Display Updated View
    deactivate DOM

    activate JS
    JS->>API: REQUEST <br/> POST https://studies.cs.helsinki.fi/exampleapp/new_note_spa <br/> Payload {"content": "New Note", "date": "2026-07-23T12:34:59.828Z"}
    deactivate JS

    activate API
    Note over API: Append JSON Data File
    API-->>JS: RESPONSE <br/> application/json charset=utf-8 <br/> Response Body: {"message":"note created"} <br/> Status Code: 201 Created
    deactivate API
```
