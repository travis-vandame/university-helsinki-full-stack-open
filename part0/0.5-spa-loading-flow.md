> **Task:** 0.5 Single Page App (SPA) Loading Flow

This diagram describes the network traffic and browser operations that occur when a user initially opens and loads the Single Page App.

```mermaid
sequenceDiagram
    autonumber
    actor User
    participant DOM as Browser
    participant JS as spa.js
    participant API as Server

    User->>DOM: Opens SPA URL
    
    activate DOM
    DOM->>API: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/spa
    deactivate DOM

    activate API
    API-->>DOM: RESPONSE <br/> Content-Type: text/html charset=utf-8 <br/> SPA HTML Code Data <br/> Status Code: 200 OK
    deactivate API

    activate DOM
    DOM->>API: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/main.css
    deactivate DOM

    activate API
    API-->>DOM: RESPONSE <br/> Content-Type: text/css charset=UTF-8 <br/> SPA CSS Code Data <br/> Status Code: 200 OK
    deactivate API

    activate DOM
    DOM->>API: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/spa.js
    deactivate DOM

    activate API
    API-->>DOM: RESPONSE <br/> Content-Type: application/javascript charset=UTF-8 <br/> SPA JavaScript Code Data <br/> Status Code: 200 OK
    Note over DOM: Parsing and Compilation of JavaScript Code
    deactivate API

    activate JS
    JS->>API: REQUEST <br/> GET https://studies.cs.helsinki.fi/exampleapp/data.json
    deactivate JS

    activate API
    API-->>JS: RESPONSE <br/> Content-Type: application/json charset=utf-8 <br/> JSON Data: [{"content": "Elmo","date": "2026-07-23"} ...] <br/> Status Code: 200 OK
    deactivate API

    activate JS
    JS->>DOM: Intercepts JSON payload & Populates List
    deactivate JS

    activate DOM
    DOM->>User: Displays rendered notes view dynamically
    deactivate DOM
```
